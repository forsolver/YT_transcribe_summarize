# Функция выбора папки сохранения

## Обзор

Добавлена возможность выбора папки для сохранения нарезанных трюков в пользовательском интерфейсе. Эта функция дает пользователям полный контроль над тем, где сохраняются обработанные видео файлы.

## Возможности

### ✅ Реализованные функции

1. **Выбор папки через интерфейс**
   - Кнопка "Выбрать папку" открывает диалог выбора папки
   - Отображение текущей выбранной папки
   - Автоматическое сокращение длинных путей с "..."
   - Tooltip с полным путем при наведении

2. **Сохранение настроек**
   - Выбранная папка сохраняется между сессиями
   - Автоматическая загрузка сохраненной папки при запуске
   - Файл настроек: `settings.json` в корне проекта

3. **Валидация папок**
   - Проверка доступности папки для записи
   - Автоматическое создание папки если она не существует
   - Визуальная индикация недоступных папок (красная рамка)

4. **Обработка ошибок**
   - Предупреждения при недоступности папки
   - Предложение выбрать альтернативную папку
   - Возврат к папке по умолчанию при ошибках

5. **Интеграция с обработкой**
   - Использование выбранной папки для одиночных видео
   - Использование выбранной папки для пакетной обработки
   - Создание структуры подпапок внутри выбранной папки

## Использование

### Для пользователей

1. **Выбор папки**:
   - Нажмите кнопку "Выбрать папку"
   - Выберите желаемую папку в диалоге
   - Папка автоматически сохранится для будущих сессий

2. **Проверка текущей папки**:
   - Текущая папка отображается в интерфейсе
   - Наведите курсор для просмотра полного пути
   - Красная рамка указывает на проблемы с доступом

3. **Обработка видео**:
   - Все трюки сохраняются в выбранной папке
   - Создается структура подпапок для организации файлов
   - Пакетная обработка также использует выбранную папку

### Для разработчиков

```python
# Получение выбранной папки в UI
output_folder = self.get_output_folder()

# Использование в обработке
downloaded_files = vp.extract_video_segments(
    video_id, 
    trick_segments, 
    output_dir=output_folder,
    video_info=video_info
)

# Создание BatchOptions с выбранной папкой
options = BatchOptions(
    max_videos=50, 
    output_dir=output_folder
)
```

## Обработка ошибок

### Типичные ошибки и решения

1. **Папка недоступна для записи**
   - Показывается предупреждение
   - Предлагается выбрать другую папку
   - Возврат к папке по умолчанию

2. **Папка не существует**
   - Автоматическое создание папки
   - Если создание невозможно - предупреждение

3. **Поврежденный файл настроек**
   - Использование настроек по умолчанию
   - Создание нового файла настроек

4. **Недостаточно места на диске**
   - Ошибка обнаруживается при обработке
   - Пользователь может выбрать другую папку
