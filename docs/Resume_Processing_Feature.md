# Функция возобновления пакетной обработки

## Обзор

Добавлена возможность возобновления пакетной обработки плейлистов и каналов после прерывания. Эта функция позволяет пользователям продолжить скачивание видео с того места, где процесс был прерван из-за внешних факторов (блокировка доступа, проблемы с интернетом, нехватка места на диске и т.д.).

## Возможности

### ✅ Реализованные функции

1. **Сохранение прогресса**
   - Автоматическое сохранение прогресса во время обработки
   - Сохранение списка обработанных видео
   - Сохранение информации о последнем обработанном видео
   - Сохранение метаданных (дата, время, количество обработанных видео)

2. **Возобновление обработки**
   - Диалог с предложением возобновить обработку
   - Отображение информации о прогрессе
   - Опция "запомнить выбор" для автоматического возобновления
   - Пропуск уже обработанных видео при возобновлении

3. **Управление состояниями**
   - Просмотр сохраненных состояний в настройках
   - Удаление выбранных состояний
   - Автоматическое удаление состояний при успешном завершении
   - Сохранение состояния при отмене пользователем

4. **Обработка изменений в источнике**
   - Обнаружение изменений в составе плейлиста/канала
   - Корректная обработка добавленных/удаленных видео
   - Предупреждения при значительных изменениях

## Технические детали

### Компоненты

#### StateManager
```python
class StateManager:
    # Управление состоянием
    save_state(source_url: str, state: dict) -> bool
    load_state(source_url: str) -> Optional[dict]
    delete_state(source_url: str) -> bool
    list_saved_states() -> List[dict]
    is_state_valid(state: dict, max_age_days: int = 7) -> bool
```

#### BatchProcessor (обновления)
```python
class BatchProcessor:
    # Поддержка возобновления
    process_source(source_url: str, options: BatchOptions, resume: bool = False) -> BatchResult
    _load_progress(source_url: str) -> Optional[dict]
    _save_progress(source_url: str, source_info: SourceInfo, videos: List[VideoInfo], ...) -> None
    _check_source_changes(source_url: str, current_videos: List[VideoInfo], saved_state: dict) -> tuple[bool, str]
```

#### ResumeDialog
```python
class ResumeDialog(QDialog):
```

### Директория состояний
- **Расположение**: `.state` в корне проекта
- **Именование файлов**: `{source_id}_state.json`
- **Идентификатор источника**: MD5-хеш от URL (первые 12 символов)

## Использование

### Для пользователей

1. **Автоматическое возобновление**:
   - При прерывании обработки прогресс сохраняется автоматически
   - При повторном запуске обработки того же источника появится диалог возобновления
   - Выберите "Возобновить" для продолжения с места прерывания
   - Выберите "Начать заново" для обработки с начала

2. **Настройка автоматического возобновления**:
   - Откройте "Настройки пакетной обработки"
   - Установите флажок "Автоматически возобновлять обработку"
   - При включенной опции диалог возобновления не будет показываться

3. **Управление сохраненными состояниями**:
   - Откройте "Настройки пакетной обработки"
   - В разделе "Сохраненные состояния обработки" отображаются все сохраненные состояния
   - Выделите строку с URL состояния, которое нужно удалить
   - Нажмите "Удалить выбранное состояние"

### Для разработчиков

```python
# Сохранение состояния
StateManager.save_state(source_url, state_dict)

# Загрузка состояния
saved_state = StateManager.load_state(source_url)

# Запуск обработки с возобновлением
processor.process_source(source_url, options, resume=True)

# Проверка изменений в источнике
changed, message = processor._check_source_changes(source_url, videos, saved_state)
```

## Обработка ошибок

### Типичные ошибки и решения

1. **Недоступный файл состояния**
   - Автоматический возврат к обработке с начала
   - Логирование ошибки для диагностики

2. **Устаревшее состояние**
   - Проверка возраста состояния (по умолчанию 7 дней)
   - Автоматическое игнорирование устаревших состояний

3. **Изменения в составе источника**
   - Обнаружение добавленных/удаленных видео
   - Предупреждение пользователя при значительных изменениях
   - Корректировка индексов для правильного возобновления

4. **Отмена пользователем**
   - Сохранение прогресса для возможности возобновления позже
   - Возможность удаления состояния через настройки
