# Руководство по ручному вводу транскрипта

## Обзор

Когда автоматическое получение транскрипта с YouTube не удается (например, из-за ограничений API или недоступности субтитров), приложение предлагает возможность ввести транскрипт вручную.

## Когда используется

Функция ручного ввода активируется в следующих случаях:
- Ошибка получения транскрипта через API YouTube
- Отсутствие автоматических субтитров для видео
- Проблемы с сетевым подключением
- Превышение лимитов запросов к YouTube API

## Как использовать

### 1. Автоматическое предложение
Когда происходит ошибка получения транскрипта, появляется диалог с вопросом:
```
Не удалось автоматически получить транскрипт: [описание ошибки]

Хотите ввести транскрипт вручную?
```

### 2. Получение транскрипта с YouTube
Для получения текста транскрипта:

1. Откройте видео на YouTube в браузере
2. Под видео нажмите кнопку "..." (Дополнительные действия)
3. Выберите "Показать расшифровку" или "Show transcript"
4. Скопируйте весь текст расшифровки

### 3. Ввод в приложение
В диалоге ручного ввода:

1. **Вставьте транскрипт** в большое текстовое поле
2. **Введите название видео** (опционально, для лучшей организации файлов)
3. Нажмите **OK**

## Поддерживаемые форматы

### Формат с временными метками
```
0:00
привет всем сегодня я покажу вам новый трюк
0:15
сначала нужно взять доску и поставить ее вот так
0:30
теперь делаем олли и сразу же поворачиваем доску
```

### Простой текстовый формат
```
привет всем сегодня я покажу вам новый трюк
сначала нужно взять доску и поставить ее вот так
теперь делаем олли и сразу же поворачиваем доску
```

## Обработка данных

После ввода транскрипта приложение:
1. **Парсит текст** на фрагменты с временными метками (если есть)
2. **Оценивает длительность** видео на основе текста
3. **Создает структуру данных** совместимую с автоматическими транскриптами
4. **Показывает подтверждение** с информацией о загруженных данных

## Функциональность

После успешного ввода ручного транскрипта доступны все функции:
- ✅ **Получить саммари** - создание краткого содержания
- ✅ **Проверить видео** - анализ на наличие трюков
- ✅ **Извлечь и скачать трюки** - поиск и скачивание сегментов

## Ограничения

- **Временные метки**: Если не указаны, все функции работают, но точность сегментирования может быть ниже
- **Качество анализа**: Зависит от полноты и точности введенного текста
- **Скачивание видео**: Требует корректный URL видео для загрузки сегментов

## Советы по использованию

### Для лучшего качества анализа:
1. **Включайте временные метки** если они доступны в YouTube
2. **Копируйте полный текст** включая все фразы и слова
3. **Проверяйте правильность** скопированного текста
4. **Указывайте название видео** для удобства организации файлов

### Для поиска трюков:
1. **Убедитесь что транскрипт включает** моменты без речи (музыкальные паузы)
2. **Временные метки помогают** точнее определить сегменты трюков
3. **Полный текст важен** для корректного анализа пауз в речи

## Пример использования

```
Сценарий: Не удается получить транскрипт для скейт-видео

1. Пользователь нажимает "Проверить видео"
2. Появляется ошибка: "Не удалось получить транскрипт"
3. Пользователь выбирает "Да" для ручного ввода
4. Открывает видео на YouTube → "..." → "Показать расшифровку"
5. Копирует текст с временными метками
6. Вставляет в диалог, указывает название "Kickflip Tutorial"
7. Нажимает OK
8. Приложение анализирует и находит 3 трюка
9. Пользователь может скачать сегменты трюков
```

## Устранение проблем

### Кнопка OK неактивна
- Убедитесь что поле транскрипта не пустое
- Введите хотя бы несколько слов текста

### Не найдены трюки
- Проверьте что транскрипт включает паузы в речи
- Убедитесь что есть сегменты только с музыкой
- Попробуйте добавить временные метки

### Ошибка при обработке
- Проверьте формат временных меток (MM:SS)
- Убедитесь что текст не содержит специальных символов
- Попробуйте упростить текст транскрипта
