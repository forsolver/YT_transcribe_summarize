# Исправление проблем с обработкой плейлистов

## Проблемы

### 1. "Не найдено видео для анализа"
- **Симптом**: При обработке плейлистов приложение сообщает "No videos found in source"
- **Причина**: Видео в плейлисте имеют ограничения доступа или требуют авторизации

### 2. Сообщения о необходимости логина
- **Симптом**: В логах появляются сообщения о возрастных ограничениях и требованиях входа в аккаунт
- **Причина**: Видео содержат контент 18+ или являются приватными

## Решения

### 1. Улучшенная функция `extract_video_list()`

**Добавлено:**
- Детальное логирование процесса извлечения
- Функция `_is_video_restricted()` для определения ограниченных видео
- Автоматическое исключение проблемных видео
- Подсчет статистики (извлечено/пропущено/ограничено)

**Код:**
```python
def _is_video_restricted(entry: dict) -> bool:
    # Проверка возрастных ограничений
    age_limit = entry.get("age_limit", 0)
    if age_limit and age_limit > 0:
        return True
    
    # Проверка требований авторизации
    availability = entry.get("availability")
    if availability in ["needs_auth", "premium_only", "subscriber_only"]:
        return True
    
    # Исключение прямых трансляций
    if entry.get("is_live") or entry.get("was_live"):
        return True
    
    return False
```

### 2. Улучшенная функция `get_video_info()`

**Добавлено:**
- Возврат информации об ограничениях (`age_limit`, `availability`)
- Обработка ошибок с определением типа ограничения
- Флаг `ignoreerrors` для продолжения работы при проблемах

### 3. Улучшенная функция `get_transcript()`

**Добавлено:**
- Проверка ограничений перед выдачей общей ошибки
- Специфичные сообщения об ошибках для разных типов ограничений

### 4. Улучшенная обработка в `batch_processor.py`

**Добавлено:**
- Подробные сообщения об ошибках для пользователя
- Объяснение возможных причин отсутствия видео

## Типы исключаемых видео

### 1. Возрастные ограничения (18+)
- **Критерий**: `age_limit > 0`
- **Сообщение**: "Skipping age-restricted video"

### 2. Требование авторизации
- **Критерии**: `availability` в ["needs_auth", "premium_only", "subscriber_only"]
- **Сообщение**: "Video requires authentication"

### 3. Прямые трансляции
- **Критерии**: `is_live` или `was_live`
- **Причина**: Проблемы с транскриптами в стримах

### 4. Недоступные видео
- **Критерии**: `entry` равен `None`
- **Причина**: Удаленные или приватные видео

## Статистика обработки

### Новые метрики:
- **Всего записей**: Количество элементов в плейлисте
- **Извлечено видео**: Успешно обработанные видео
- **Пропущено**: Недоступные или поврежденные записи
- **Ограничено по возрасту**: Видео с возрастными ограничениями

### Пример вывода:
```
Video extraction completed: 15 videos extracted, 3 skipped, 2 age-restricted
```
