# Обработка видео с ограничениями

## Обзор

YouTube содержит видео с различными ограничениями доступа, которые могут препятствовать автоматической обработке. Приложение теперь умеет распознавать и корректно обрабатывать такие видео.

## Типы ограничений

### 1. Возрастные ограничения
- **Описание**: Видео с контентом для взрослых (18+)
- **Требования**: Вход в аккаунт YouTube для подтверждения возраста
- **Обработка**: Автоматически исключаются из пакетной обработки

### 2. Требование авторизации
- **Описание**: Приватные видео или видео для подписчиков
- **Требования**: Вход в аккаунт и соответствующие права доступа
- **Обработка**: Исключаются с соответствующим сообщением

### 3. Премиум контент
- **Описание**: Видео, доступные только по подписке YouTube Premium
- **Требования**: Активная подписка YouTube Premium
- **Обработка**: Исключаются из обработки

### 4. Прямые трансляции
- **Описание**: Живые стримы или записи стримов
- **Проблемы**: Часто имеют проблемы с транскриптами
- **Обработка**: Исключаются для стабильности

## Алгоритм обнаружения

### В функции `_is_video_restricted()`:

```python
def _is_video_restricted(entry: dict) -> bool:
    # 1. Проверка возрастных ограничений
    age_limit = entry.get("age_limit", 0)
    if age_limit and age_limit > 0:
        return True
    
    # 2. Проверка статуса доступности
    availability = entry.get("availability")
    if availability in ["needs_auth", "premium_only", "subscriber_only"]:
        return True
    
    # 3. Проверка прямых трансляций
    if entry.get("is_live") or entry.get("was_live"):
        return True
    
    # 4. Проверка заголовка на ключевые слова
    title = entry.get("title", "").lower()
    restricted_keywords = ["age restricted", "sign in", "login required", "private video"]
    if any(keyword in title for keyword in restricted_keywords):
        return True
    
    return False
```

if not transcript:
    # Проверка на ограничения
    try:
        video_info_check = get_video_info(video_id)
        if video_info_check.get("age_limit", 0) > 0:
            raise RuntimeError("Видео имеет возрастные ограничения и требует входа в аккаунт")
        elif video_info_check.get("availability") in ["needs_auth", "premium_only", "subscriber_only"]:
            raise RuntimeError("Видео требует авторизации или подписки")
    except Exception:
        pass
    
    raise RuntimeError("Не удалось получить транскрипт")

• Проблемы с доступом к YouTube API

## Рекомендации пользователям

### Для максимальной совместимости:
1. **Используйте публичные плейлисты** без возрастных ограничений
2. **Проверяйте доступность** видео перед пакетной обработкой
3. **Учитывайте ограничения** при планировании обработки больших плейлистов

### При проблемах с доступом:
1. **Проверьте URL** плейлиста или канала
2. **Убедитесь в публичности** контента
3. **Попробуйте другой плейлист** для тестирования
