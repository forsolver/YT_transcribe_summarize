# Реализация функции ручного ввода транскрипта

## Обзор изменений

Добавлена функциональность ручного ввода транскрипта для случаев, когда автоматическое получение транскрипта с YouTube не удается.

## Реализованные компоненты

### 1. ManualTranscriptDialog (ytsummarizer/ui.py)

**Новый класс диалога для ручного ввода транскрипта:**

- **Интуитивный интерфейс**: Подробные инструкции по получению транскрипта с YouTube
- **Поле ввода транскрипта**: Большое текстовое поле с примером формата
- **Поле названия видео**: Опциональное поле для лучшей организации файлов
- **Валидация ввода**: Кнопка OK активна только при наличии текста
- **Парсинг транскрипта**: Автоматическое разделение на фрагменты с временными метками
- **Оценка длительности**: Приблизительный расчет длительности видео

**Ключевые методы:**
- `parse_manual_transcript()` - парсинг текста в структурированные фрагменты
- `estimate_duration_from_fragments()` - оценка длительности видео
- `get_transcript_data()` - получение обработанных данных

### 2. Модификация _fetch_transcript_data()

**Улучшенная обработка ошибок:**
- При ошибке получения транскрипта предлагается ручной ввод
- Интеграция с новым диалогом ManualTranscriptDialog
- Сохранение совместимости с существующим кодом

### 3. Новый метод _get_manual_transcript()

**Обработка ручного ввода:**
- Показ диалога ручного ввода
- Обработка введенных данных
- Создание структуры данных совместимой с автоматическими транскриптами
- Отображение подтверждения успешной загрузки

### 4. Модификация методов обработки

**Обновлены все основные методы:**
- `run_summarize()` - саммаризация с поддержкой ручного ввода
- `run_check_video()` - анализ видео с ручным транскриптом
- `run_download_tricks()` - скачивание трюков с ручным транскриптом

**Логика обработки:**
1. Попытка автоматического получения транскрипта
2. При ошибке - предложение ручного ввода
3. Повторная проверка данных после ручного ввода
4. Продолжение обработки с полученными данными

## Поддерживаемые форматы транскрипта

### Формат с временными метками
```
0:00
текст первого фрагмента
0:15
текст второго фрагмента
1:30
текст третьего фрагмента
```

### Простой текстовый формат
```
весь текст транскрипта без временных меток
будет обработан как один фрагмент
```

## Алгоритм парсинга

1. **Разделение на строки**: Текст разбивается по символам новой строки
2. **Поиск временных меток**: Строки в формате MM:SS определяются как временные метки
3. **Группировка текста**: Текст между временными метками объединяется в фрагменты
4. **Создание структуры**: Каждый фрагмент получает время начала и текст
5. **Вычисление длительности**: Для каждого фрагмента рассчитывается длительность:
   - Для фрагментов с временными метками: разность между соседними метками
   - Для последнего фрагмента: оценка на основе количества слов (0.5 сек/слово)
6. **Обработка исключений**: Если временные метки не найдены, весь текст становится одним фрагментом

## Интеграция с существующими функциями

### Полная совместимость
- **video_processor.extract_trick_segments()** - работает с ручными транскриптами
- **summarizer.create_summary()** - создает саммари из ручного текста
- **video_processor.extract_video_segments()** - скачивает сегменты по ручным данным

### Структура данных
Ручные транскрипты создают ту же структуру данных, что и автоматические:
```python
fragments = [
    {
        'start': 0,        # время начала в секундах
        'text': 'текст',   # текст фрагмента
        'duration': 15.0   # длительность фрагмента в секундах
    },
    # ...
]

video_info = {
    'title': 'название видео',
    'duration': 180.5  # длительность в секундах
}
```

## Пользовательский опыт

### Сценарий использования
1. Пользователь нажимает любую кнопку обработки
2. Происходит ошибка получения транскрипта
3. Появляется диалог: "Хотите ввести транскрипт вручную?"
4. При согласии открывается диалог ввода с инструкциями
5. Пользователь копирует транскрипт с YouTube и вставляет
6. После подтверждения все функции становятся доступными

### Преимущества
- **Надежность**: Работает даже при проблемах с YouTube API
- **Гибкость**: Поддержка различных форматов транскрипта
- **Простота**: Интуитивный интерфейс с подробными инструкциями
- **Совместимость**: Полная интеграция с существующими функциями
