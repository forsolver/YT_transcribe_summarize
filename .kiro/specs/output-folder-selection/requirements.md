# Requirements Document

## Introduction

Добавление возможности выбора папки для сохранения нарезанных трюков в пользовательском интерфейсе. Это улучшение даст пользователям больше контроля над тем, где сохраняются обработанные видео файлы.

## Requirements

### Requirement 1

**User Story:** Как пользователь, я хочу выбирать папку для сохранения нарезанных трюков, чтобы контролировать, где хранятся мои файлы.

#### Acceptance Criteria

1. WHEN пользователь открывает приложение THEN система SHALL отображать текущую папку для сохранения трюков
2. WHEN пользователь нажимает кнопку "Выбрать папку" THEN система SHALL открыть диалог выбора папки
3. WHEN пользователь выбирает папку в диалоге THEN система SHALL обновить отображаемый путь к папке
4. WHEN пользователь выбирает папку THEN система SHALL сохранить выбор для последующих сессий
5. IF пользователь не выбрал папку THEN система SHALL использовать папку по умолчанию "tricks"

### Requirement 2

**User Story:** Как пользователь, я хочу видеть текущую выбранную папку в интерфейсе, чтобы знать, куда будут сохранены файлы.

#### Acceptance Criteria

1. WHEN приложение запускается THEN система SHALL отображать текущую папку для сохранения
2. WHEN пользователь изменяет папку THEN система SHALL немедленно обновить отображение
3. IF путь к папке слишком длинный THEN система SHALL отображать сокращенную версию с "..."
4. WHEN пользователь наводит курсор на путь THEN система SHALL показать полный путь в tooltip

### Requirement 3

**User Story:** Как пользователь, я хочу, чтобы выбранная папка использовалась для всех операций сохранения трюков, чтобы все файлы были в одном месте.

#### Acceptance Criteria

1. WHEN пользователь запускает извлечение трюков для одного видео THEN система SHALL использовать выбранную папку
2. WHEN пользователь запускает пакетную обработку THEN система SHALL использовать выбранную папку как базовую
3. WHEN система создает структуру папок THEN она SHALL создавать подпапки внутри выбранной папки
4. IF выбранная папка недоступна THEN система SHALL показать ошибку и предложить выбрать другую папку

### Requirement 4

**User Story:** Как пользователь, я хочу, чтобы настройка папки сохранялась между сессиями, чтобы не выбирать её каждый раз.

#### Acceptance Criteria

1. WHEN пользователь выбирает папку THEN система SHALL сохранить путь в настройках приложения
2. WHEN пользователь перезапускает приложение THEN система SHALL загрузить сохраненный путь к папке
3. IF сохраненная папка не существует THEN система SHALL вернуться к папке по умолчанию
4. WHEN пользователь сбрасывает настройки THEN система SHALL вернуться к папке по умолчанию "tricks"
