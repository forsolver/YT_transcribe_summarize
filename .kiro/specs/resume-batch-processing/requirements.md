# Requirements Document

## Introduction

Добавление возможности возобновления пакетной обработки плейлистов и каналов после прерывания работы скрипта. Эта функция позволит пользователям продолжить скачивание видео с того места, где процесс был прерван из-за внешних факторов (блокировка доступа, проблемы с интернетом, нехватка места на диске и т.д.).

## Requirements

### Requirement 1

**User Story:** Как пользователь, я хочу иметь возможность возобновить пакетную обработку плейлиста с того места, где она была прервана, чтобы не начинать процесс заново при возникновении проблем.

#### Acceptance Criteria

1. WHEN пользователь запускает пакетную обработку THEN система SHALL сохранять прогресс обработки в файл состояния
2. WHEN пакетная обработка прерывается THEN система SHALL сохранять информацию о последнем обработанном видео
3. WHEN пользователь перезапускает обработку того же источника THEN система SHALL предлагать возобновить с места прерывания
4. IF пользователь соглашается возобновить обработку THEN система SHALL пропускать уже обработанные видео
5. IF пользователь отказывается возобновить обработку THEN система SHALL начать обработку с начала

### Requirement 2

**User Story:** Как пользователь, я хочу видеть информацию о прогрессе обработки и возможности возобновления, чтобы понимать текущее состояние процесса.

#### Acceptance Criteria

1. WHEN система обнаруживает сохраненный прогресс THEN она SHALL показывать количество уже обработанных видео
2. WHEN система предлагает возобновить обработку THEN она SHALL отображать информацию о последнем обработанном видео
3. WHEN пакетная обработка завершается успешно THEN система SHALL удалять файл состояния для этого источника
4. WHEN пользователь отменяет обработку вручную THEN система SHALL сохранять прогресс для возможности возобновления

### Requirement 3

**User Story:** Как пользователь, я хочу иметь возможность управлять сохраненными состояниями обработки, чтобы при необходимости начать процесс заново.

#### Acceptance Criteria

1. WHEN пользователь открывает настройки пакетной обработки THEN система SHALL отображать список сохраненных состояний
2. WHEN пользователь выбирает сохраненное состояние THEN система SHALL предоставлять опцию удаления этого состояния
3. WHEN пользователь удаляет состояние THEN система SHALL начинать обработку этого источника с начала при следующем запуске
4. WHEN система сохраняет состояние THEN она SHALL включать метаданные (дата, время, количество обработанных видео)

### Requirement 4

**User Story:** Как разработчик, я хочу, чтобы система корректно обрабатывала изменения в плейлистах и каналах, чтобы возобновление работало даже при изменении содержимого источника.

#### Acceptance Criteria

1. WHEN система возобновляет обработку THEN она SHALL проверять изменения в составе плейлиста/канала
2. IF в плейлист добавлены новые видео THEN система SHALL обрабатывать только новые и пропущенные видео
3. IF из плейлиста удалены видео THEN система SHALL корректно обновлять информацию о прогрессе
4. WHEN система обнаруживает значительные изменения в источнике THEN она SHALL предупреждать пользователя
