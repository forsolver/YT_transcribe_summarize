# YouTube Инструменты: Транскрипция, Саммаризация и Извлечение Трюков

## Быстрый старт

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

   (Если используете `pip`<21.3, добавьте `--use-pep517`, т.к. `yt-dlp` собирается через PEP517.)

2. Экспортируйте ключ OpenAI в переменную окружения (Windows PowerShell):
   ```powershell
   setx OPENAI_API_KEY "sk-..."
   ```

3. Запустите приложение:
   ```bash
   python -m ytsummarizer.app
   ```
   Теперь приложение называется "YouTube Инструменты" и включает не только саммаризацию, но и извлечение трюков.

## Основные функции

*   **Саммаризация видео**: Получение краткого содержания видео на основе его транскрипта с использованием OpenAI.
*   **Извлечение трюков**: Автоматическое определение временных сегментов в видео (например, спортивных), где выполняются трюки. Это делается путем анализа транскрипта на наличие "тихих" участков или участков с минимальным количеством текста (например, только музыка).
*   **Пакетная обработка**: Обработка целых каналов и плейлистов YouTube для массового извлечения трюков из множества видео одновременно.
*   **Выбор папки сохранения**: Пользователи могут выбирать, в какую папку на локальном компьютере сохранять нарезанные трюки.
*   **Ручной ввод транскрипта**: Когда автоматическое получение транскрипта не удается, пользователь может вручную ввести текст для анализа.

## Что нового

### Пакетная обработка каналов и плейлистов (v1.0)

* **Поддержка каналов и плейлистов**: Теперь можно вводить ссылки на целые каналы YouTube или плейлисты для массовой обработки видео.
* **Автоматическое определение типа URL**: Приложение автоматически определяет, является ли введенная ссылка одиночным видео, каналом или плейлистом.
* **Структурированное хранение**: Создается вложенная структура папок `tricks/[название_канала_или_плейлиста]/[название_видео]/` для удобной организации результатов.
* **Прогресс-индикаторы**: Отображение общего прогресса обработки и текущего обрабатываемого видео.
* **Настройки пакетной обработки**: Возможность ограничить количество обрабатываемых видео, пропускать уже обработанные файлы.
* **Отмена операций**: Возможность отменить длительную пакетную обработку без потери уже обработанных данных.
* **Устойчивость к ошибкам**: Ошибка в одном видео не останавливает обработку остальных видео в пакете.
* **Подробная отчетность**: Детальная статистика по завершении обработки с информацией об ошибках.

### Примеры использования пакетной обработки:

* **Канал**: `https://www.youtube.com/@channelname` или `https://www.youtube.com/channel/UC...`
* **Плейлист**: `https://www.youtube.com/playlist?list=PL...`
* **Одиночное видео**: `https://www.youtube.com/watch?v=...` (работает как раньше)

### Выбор папки сохранения (v1.1)

* **Настраиваемая папка сохранения**: Пользователи могут выбирать любую папку на компьютере для сохранения нарезанных трюков.
* **Сохранение настроек**: Выбранная папка сохраняется между сессиями приложения.
* **Визуальная индикация**: Отображение текущей папки с сокращением длинных путей и tooltip с полным путем.
* **Валидация папок**: Автоматическая проверка доступности папки для записи с предупреждениями при ошибках.
* **Обработка ошибок**: Предложение выбрать альтернативную папку при проблемах с доступом.
* **Интеграция**: Работает как для одиночных видео, так и для пакетной обработки.

* Значительно улучшено качество скачиваемых видео:
  * Теперь используется максимально доступное качество (до 4K) через `yt-dlp` с форматом `bestvideo+bestaudio/best`
  * Автоматический мердж аудио и видео в MP4

### Ручной ввод транскрипта (v1.1)

* **Резервный способ получения транскрипта**: Когда автоматическое получение транскрипта не удается (ошибки API, отсутствие субтитров), пользователю предлагается ввести транскрипт вручную.
* **Интуитивный интерфейс**: Простой диалог с инструкциями по получению транскрипта с YouTube.
* **Поддержка временных меток**: Автоматический парсинг транскрипта с временными метками в формате MM:SS.
* **Гибкость форматов**: Поддержка как транскриптов с временными метками, так и простого текста.
* **Полная совместимость**: Ручные транскрипты работают со всеми функциями: саммаризация, анализ трюков, скачивание сегментов.
* **Умная обработка**: Автоматическая оценка длительности видео и создание структуры данных совместимой с автоматическими транскриптами.

### Как использовать ручной ввод:
1. При ошибке получения транскрипта выберите "Да" в диалоге
2. Откройте видео на YouTube → "..." → "Показать расшифровку"
3. Скопируйте текст и вставьте в диалог приложения
4. Укажите название видео (опционально)
5. Все функции теперь доступны для анализа

### Исправления и улучшения (v1.1.2):
* **Исправлена ошибка 'duration'**: Ручные транскрипты теперь корректно обрабатываются анализатором трюков
* **Улучшен расчет длительности**: Автоматическое вычисление длительности фрагментов на основе временных меток
* **Повышена надежность**: Полная совместимость ручных транскриптов с существующими алгоритмами
* **Улучшена обработка плейлистов**: Автоматическое исключение видео с возрастными ограничениями и требованиями авторизации
* **Расширенное логирование**: Подробная информация о процессе извлечения видео и причинах ошибок
* **Умная фильтрация**: Исключение проблемных видео (прямые трансляции, приватные, премиум-контент)
* **Улучшенная отчетность**: Детальная статистика обработки с указанием причин пропуска видео

Подробное руководство: [docs/Manual_Transcript_Guide.md](docs/Manual_Transcript_Guide.md)
  * Сохранение исходного качества при нарезке через ffmpeg с `-c copy`
  * Улучшенные имена файлов с указанием длительности
  * Минимальная длительность трюков увеличена до 10 секунд для лучшего восприятия

* Улучшен алгоритм извлечения `video_id` из ссылок YouTube — теперь корректно обрабатываются:
  * полноформатные ссылки вида `https://www.youtube.com/watch?v=<ID>&...`;
  * короткие ссылки `https://youtu.be/<ID>`;
  * embed-ссылки `/embed/<ID>` и `/v/<ID>`;
  * а также случай, когда пользователь вставляет уже готовый идентификатор.

* Если указан `video_id` длиной 11 символов без ссылки, приложение работает с ним напрямую.

* Добавлена поддержка приватных/возраст-ограниченных видео — библиотека `youtube-transcript-api` теперь читает cookies из файла. Экспортируйте cookies из браузера (формат Netscape, например расширение Cookie-Editor) и сохраните их в `cookies.txt` рядом с `main.py` либо задайте путь через переменную **YOUTUBE_COOKIES_FILE**.

Благодаря этому исправлению ошибка «Не удалось найти доступный транскрипт для этого видео» больше не появляется для ссылок с дополнительными параметрами (`&t=30s`, `&ab_channel=...` и т. д.).

* Реализован fallback на **yt-dlp**: если `youtube-transcript-api` не смогла достать субтитры, скрипт пробует через `yt-dlp` и парсит WebVTT. Поддерживаются как настоящие, так и авто-сгенерированные дорожки. Приоритет языков: `ru`, затем `en`.

## Как получить cookies для YouTube

Для корректной работы с приватными, возраст-ограниченными и некоторыми публичными видео YouTube требуется авторизационный cookie-файл (Netscape формат).

**Пошаговая инструкция:**

1. **Откройте YouTube в браузере, где вы залогинены.**

2. **Установите расширение [Cookie-Editor](https://chrome.google.com/webstore/detail/cookie-editor/fngmhnnpilhplaeedifhccceomclgfbg) (или аналогичное) для вашего браузера.**

3. **Находясь на youtube.com, откройте Cookie-Editor и выберите «Экспортировать» (Export).**
   - Формат экспорта: Netscape (обычно по умолчанию)
   - Скопируйте содержимое в файл `cookies.txt` (или другое имя, если хотите)

4. **Положите файл `cookies.txt` рядом с `main.py`** (или укажите путь к нему через переменную окружения `YOUTUBE_COOKIES_FILE`).

5. **Какие куки нужны?**
   - Достаточно экспортировать все cookies для домена `.youtube.com` (расширение делает это автоматически).
   - Ключевые куки: `SID`, `HSID`, `SSID`, `APISID`, `SAPISID`, `LOGIN_INFO`, `YSC`, `VISITOR_INFO1_LIVE`, `PREF`, а также `__Secure-3PAPISID`, `__Secure-3PSID`, `__Secure-3PSIDCC` и др. — но проще экспортировать всё.

6. **Обновляйте cookies при необходимости** (например, если скрипт снова начнёт выдавать ошибку — возможно, срок действия куки истёк).

**Важно:** не публикуйте свой cookies.txt — он даёт доступ к вашему аккаунту!

## Известные ограничения

* Если авто-субтитры действительно недоступны на YouTube, приложение продолжит выводить сообщение об ошибке.
* Библиотека `youtube-transcript-api` может не работать за корпоративным прокси или при блокировках YouTube. При необходимости используйте переменную окружения `HTTPS_PROXY`.

## Требования к системе

* **ffmpeg**: требуется для обработки видео
  * Windows: установите через Chocolatey или скачайте [официальный билд](https://ffmpeg.org/download.html)
  * Убедитесь, что ffmpeg доступен в PATH
  * Рекомендуемый путь установки в Windows: `C:\ProgramData\chocolatey\lib\ffmpeg\tools\ffmpeg\bin`

## Ярлык на рабочем столе Windows

1. Щёлкните правой кнопкой мыши по рабочему столу → «Создать» → «Ярлык».
2. В поле «Расположение объекта» введите:

```
%SystemRoot%\System32\cmd.exe /k "cd /d <ПУТЬ_К_ПРОЕКТУ> && run.bat"
```

   Замените `<ПУТЬ_К_ПРОЕКТУ>` на полный путь к папке репозитория.

3. Нажмите «Далее», задайте имя (например, *YouTube Summarizer*), «Готово».

4. (Необязательно) Смените значок: Свойства ярлыка → «Сменить значок» → укажите любой `ico`.

Ярлык запускает `run.bat`, который активирует виртуальное окружение (если нужно) и стартует GUI командой `python -m ytsummarizer.app`.
